# 使用说明 / 测试流程

打开小程序后，底部有 4 个 tab：**我的申请 / 新建申请 / 待我审批 / 审批人管理**。

> 提醒：小程序目前是体验版，需要先被加进「成员管理」里的体验成员名单才能打开。

## 如果你是"提申请的人"

1. 点「审批人管理」
2. 在「我要邀请审批人」里点「生成邀请」，会出现「转发给对方」和「生成二维码」两个按钮
3. 点「转发给对方」，在微信聊天里选人发送；如果是当面场景，可以点「生成二维码」，让对方直接扫码
4. 等对方完成绑定后，回到「新建申请」，填写商品名称、价格、理由，选择审批人
5. 点「提交申请」（提交前会弹出订阅消息授权，点「允许」才能收到审批结果通知）
6. 想催一下的话，可以在提交成功页或者详情页点「转发给审批人」
7. 想看结果，随时点「我的申请」；也可以按状态筛选

### 撤回和再次编辑

- **撤回**：状态为「审批中」的申请，可以在「我的申请」卡片上或详情页点「撤回申请」，撤回后状态变成「已撤回」
- **编辑**：状态为「已撤回」的申请，点「编辑并重新提交」，会自动带出原来的内容；改完点「重新提交」，这条申请会重新变回「审批中」，并再次通知审批人
- 已经通过或未通过的申请，不能撤回，也不能编辑

## 如果你是"负责审批的人"

1. 收到对方发来的转发卡片，直接点开；或者用微信「扫一扫」扫描对方给的二维码
2. 打开后会自动进入「审批人管理」页面，出现「确认绑定为审批人」，**不需要输入任何邀请码**，只要填一下你的称呼（对方会看到这个名字）
3. 点「确认绑定」
4. 之后进入「待我审批」时，会弹出订阅消息授权，点「允许」才能收到新申请的通知
5. 有新申请时，在「待我审批」里点「通过」或「驳回」，可以写审批意见

## 收不到微信通知怎么办

- 订阅消息是**一次性授权**：每点一次「允许」，才能收到一条通知，用完就要重新授权
- 通知会出现在微信的「服务通知」里，不是小程序内
- 需要在**真机**上测试，模拟器收不到
- 通知发不出去不会影响审批本身，申请和审批结果都以小程序里的数据为准
